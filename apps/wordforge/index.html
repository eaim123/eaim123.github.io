CLI + GUI

Utilícelo como usted prefiera

Puede trabajar desde la interfaz gráfica o utilizar directamente RSC WordForge desde la terminal de Kali Linux.

kali@rsc:~
$ rsc-wordforge start
$ rsc-wordforge generate --min 4 --max 4 --preset digits --output numeros.txt
$ rsc-wordforge pattern --template "@@%%" --output wordlist.txt
$ rsc-wordforge estimate --min 6 --max 6 --preset alnum
$ rsc-wordforge status
Kali Linux

Instalar RSC WordForge

Descargue el paquete Debian oficial de RSC WordForge 0.1.0 e instálelo directamente en Kali Linux.

Descargar RSC WordForge 0.1.0 Ver código en GitHub

Kali Linux • AMD64 • Versión 0.1.0

SHA-256: e0016460262e7e539befda6215befa2232c51be53163d38b923ad370fb84569d

1. Actualizar los repositorios
$ sudo apt update
2. Instalar el paquete descargado
$ sudo apt install ./rsc-wordforge_0.1.0_amd64.deb
3. Iniciar RSC WordForge
$ rsc-wordforge start
Después de la instalación también puede iniciar RSC WordForge desde el menú de aplicaciones de Kali Linux.
