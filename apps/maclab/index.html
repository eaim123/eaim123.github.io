RSC MacLab

Laboratorio educativo de identidad de red para Kali Linux que permite analizar, generar y modificar direcciones MAC, identificar fabricantes mediante OUI y restaurar de forma controlada la dirección MAC permanente de una interfaz.

Versión 0.1.0 • Kali Linux • GUI + Motor nativo

Funcionalidades

Controle y analice su identidad MAC

RSC MacLab reúne análisis, generación, cambio y restauración de direcciones MAC dentro de una única herramienta visual para Kali Linux.

🖧

Interfaces de red

Detecta las interfaces disponibles y muestra estado, IPv4, MAC actual y datos asociados.

🔍

Análisis OUI

Analiza el prefijo OUI, fabricante, bits I/G y U/L y clasifica la dirección MAC seleccionada.

⚙️

Generación flexible

Genere direcciones aleatorias, conserve el OUI, seleccione un fabricante o introduzca una MAC manual.

↩️

Restauración

Detecta la MAC permanente mediante el sistema y permite restaurarla cuando la identidad ha sido modificada.

⚡

Motor nativo

RSC MacLab incorpora un motor propio escrito en C para efectuar el cambio de dirección MAC.

🌐

Conectividad preservada

El motor evita bajar explícitamente la interfaz, permitiendo conservar la configuración IPv4 cuando el controlador lo admite.

Modos de identidad

Elija cómo generar la nueva MAC

MacLab ofrece diferentes estrategias para crear una identidad de red según el laboratorio o escenario que desee estudiar.

Aleatoria Dirección local Unicast generada automáticamente
Mismo OUI Conserva el fabricante de la MAC actual
Fabricante VMware, Cisco, Xerox, VirtualBox y otros
Manual Introduzca y valide su propia dirección MAC
Network Identity

Entienda qué representa una dirección MAC

MacLab analiza distintos componentes de la identidad hardware y los presenta de forma sencilla dentro del dashboard.

OUI

Fabricante

Identifica el prefijo organizacional asociado a la dirección.

I/G

Individual / Group

Determina si la dirección es Unicast o Multicast.

U/L

Universal / Local

Determina si la dirección es universal o administrada localmente.

PERM

MAC permanente

Compara la dirección actual con la identidad permanente del adaptador.

Utilícelo como usted prefiera

Puede trabajar desde la interfaz gráfica o utilizar directamente RSC MacLab desde la terminal de Kali Linux.

kali@rsc:~
rsc-maclab start
rsc-maclab status
rsc-maclab version
Kali Linux

Instalar RSC MacLab

Descargue el paquete Debian oficial de RSC MacLab 0.1.0 e instálelo directamente en Kali Linux.

Descargar RSC MacLab 0.1.0 Ver código en GitHub

Kali Linux • AMD64 • Versión 0.1.0

SHA-256: c34b7e57a4bd15967af802c32a152015da0b38a9d883ce1fe9ede73395de8405

1. Actualizar los repositorios
sudo apt update
2. Instalar el paquete descargado
sudo apt install ./rsc-maclab_0.1.0_amd64.deb
3. Iniciar RSC MacLab
rsc-maclab start
Después de la instalación también puede iniciar RSC MacLab desde el menú de aplicaciones de Kali Linux.
