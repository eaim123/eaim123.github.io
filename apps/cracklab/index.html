Funcionalidades

Un laboratorio de análisis y recuperación

Diferentes motores de análisis y validación reunidos dentro de una misma herramienta educativa.

#

Análisis de hashes

Detecta automáticamente tipos probables de hash y permite realizar búsquedas mediante wordlists.

📦

Archivos comprimidos

Analiza archivos ZIP, RAR4, RAR5 y 7Z protegidos mediante contraseña.

📄

Documentos PDF

Soporte para PDF Standard Security Handler desde R2 hasta R6.

🗂️

Microsoft Office

Analiza documentos DOCX, XLSX y PPTX protegidos con Standard Encryption o Agile Encryption.

⚙️

Perfiles de rendimiento

Seleccione perfiles Eco, Balanceado o Máximo según los recursos disponibles.

⚡

Multiproceso

Distribuye el trabajo entre varios procesos cuando el motor lo permite.

Motores disponibles

Formatos soportados

RSC CrackLab detecta diferentes mecanismos de protección y selecciona el motor de validación correspondiente.

HASH Wordlists
ZIP ZipCrypto
RAR RAR4 / RAR5
7Z 7zAES
PDF R2 - R6
DOCX Microsoft Word
XLSX Microsoft Excel
PPTX Microsoft PowerPoint
Motores criptográficos

Distintas generaciones de protección

CrackLab identifica el esquema de cifrado antes de seleccionar el motor adecuado.

RC4

Soporte para PDF RC4 de 40 y 128 bits mediante Standard Security Handler.

AES

Soporte para AES-128 y AES-256 utilizado por PDF, Office y 7Z.

Office

Standard Encryption y Agile Encryption con mecanismos SHA-1, SHA-256, SHA-384 y SHA-512.

Instalar RSC CrackLab

Descargue el paquete Debian oficial de RSC CrackLab 0.1.0 para Kali Linux. APT instalará automáticamente las dependencias declaradas por el paquete.

Descargar RSC CrackLab 0.1.0 Ver código fuente en GitHub

Kali Linux • AMD64 • Versión 0.1.0 • Paquete Debian

SHA-256 del instalador SHA256_FINAL_AQUI
1. Actualizar los repositorios de Kali Linux:
sudo apt update
2. Instalar RSC CrackLab:
sudo apt install ./rsc-cracklab_0.1.0_amd64.deb
3. Abrir RSC CrackLab:
rsc-cracklab
Ver información del Release v0.1.0 →
Antes de instalar RSC CrackLab se recomienda ejecutar sudo apt update.

RSC CrackLab está orientado a Kali Linux AMD64 e incluye interfaces GUI y CLI.

Algunas funciones RAR requieren que el backend unrar esté disponible en el sistema.

Próximamente RSC contará con su propio repositorio APT.
RSC Education

Creado para aprender y experimentar

RSC CrackLab forma parte de la familia de herramientas educativas RSC. Su propósito es facilitar el estudio práctico de hashes, mecanismos de protección de archivos, criptografía aplicada y recuperación de contraseñas dentro de entornos controlados. Utilice la herramienta únicamente sobre archivos, sistemas y datos propios o para los cuales cuente con autorización.
