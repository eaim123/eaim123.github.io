RSC StegLab en acción

RSC StegLab proporciona una interfaz gráfica para trabajar con los diferentes motores de esteganografía de manera sencilla y visual.

Interfaz gráfica de RSC StegLab 0.6.0 ejecutándose en Kali Linux.

Funcionalidades

Un laboratorio multimedia

RSC StegLab reúne diferentes técnicas de esteganografía dentro de una sola herramienta educativa.

🔎

Analizar

Examina las características del carrier y estima automáticamente su capacidad esteganográfica.

🧪

Inspeccionar

Detecta payloads de RSC StegLab y muestra información sobre el archivo oculto.

🔐

Ocultar

Oculta archivos dentro de imágenes, audio o video y permite protegerlos mediante contraseña.

📤

Extraer

Recupera archivos ocultos, descifra el contenido y comprueba automáticamente su integridad.

Motores disponibles

Formatos soportados

Cada tipo de carrier utiliza una técnica adaptada a las características de su formato.

PNG LSB sobre canales de imagen
JPEG Coeficientes DCT
WAV PCM / LSB de muestras
MKV FFV1 / Luma-LSB
MP4 H.264 Lossless QP=0
Protección

Cifrado e integridad

El payload puede protegerse mediante cifrado y verificar su integridad después de la extracción.

AES-GCM

Protección opcional del archivo oculto mediante contraseña y cifrado autenticado.

SHA-256

Comprobación de que el archivo recuperado coincide exactamente con el archivo original.

Payload v2

Formato propio de RSC StegLab con soporte para cifrado, metadatos e integridad.

CLI + GUI

Utilícelo como usted prefiera

Puede trabajar mediante la interfaz gráfica o utilizar directamente los comandos de RSC StegLab desde la terminal.

kali@rsc:~
rsc-steglab start
rsc-steglab analyze imagen.png
rsc-steglab inspect carrier.jpg
rsc-steglab hide carrier.png secreto.pdf --password
rsc-steglab extract carrier.png

Instalar RSC StegLab

Descargue el paquete Debian oficial de RSC StegLab 0.6.0 para Kali Linux. APT instalará automáticamente las dependencias necesarias para ejecutar la aplicación.

1. Actualizar los repositorios de Kali Linux:
sudo apt update
2. Instalar RSC StegLab:
sudo apt install ./rsc-steglab_0.6.0_amd64.deb
3. Abrir RSC StegLab:
rsc-steglab start
