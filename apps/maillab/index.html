Funcionalidades

Construya y envíe sus mensajes

MailLab reúne composición, validación, previsualización y envío de correo dentro de una sola herramienta educativa.

✉️

Gmail SMTP

Utiliza cuentas Gmail mediante App Password para realizar envíos SMTP autenticados.

👥

Listas de destinatarios

Envíe a un destinatario individual o cargue listas desde archivos de texto.

🌐

Texto y HTML

Cree mensajes en texto plano o utilice HTML con una vista previa renderizada antes del envío.

📎

Archivos adjuntos

Incorpore uno o varios archivos al mensaje antes de realizar el envío.

🧩

Plantillas HTML

Guarde, cargue, actualice y reutilice diseños HTML directamente desde MailLab.

🪪

Nombre visible

Configure el nombre que acompañará a la dirección Gmail como identificación visual del remitente.

Kali Linux

Inicie MailLab desde la terminal

Después de instalar el paquete puede iniciar la interfaz gráfica desde el menú de aplicaciones o directamente desde la terminal.

kali@rsc:~
$ rsc-maillab start
$ rsc-maillab version
$ rsc-maillab status
Kali Linux

Instalar RSC MailLab

Descargue el paquete Debian oficial de RSC MailLab 0.1.0 e instálelo directamente en Kali Linux.

Descargar RSC MailLab 0.1.0 Ver código en GitHub

Kali Linux • AMD64 • Versión 0.1.0 • Paquete Debian

1. Actualizar los repositorios
$ sudo apt update
2. Instalar el paquete descargado
$ sudo apt install ./rsc-maillab_0.1.0_amd64.deb
3. Iniciar RSC MailLab
$ rsc-maillab start
Después de la instalación también puede iniciar RSC MailLab desde el menú de aplicaciones de Kali Linux.

Para utilizar Gmail SMTP debe configurar una cuenta Gmail compatible con App Password.
