RSC TargetLab

Laboratorio multiprotocolo de autenticación para prácticas controladas de ciberseguridad. Permite levantar servicios reales de laboratorio, trabajar con diferentes perfiles de credenciales y analizar el comportamiento de los mecanismos de autenticación y bloqueo.

Funcionalidades

Un laboratorio para practicar autenticación

RSC TargetLab proporciona objetivos de autenticación controlados para realizar prácticas desde clientes y herramientas utilizadas habitualmente en Kali Linux.

🌐

Múltiples protocolos

Trabaje con servicios de red, web, directorio y bases de datos desde una única aplicación de laboratorio.

🔑

Perfiles de credenciales

Utilice diferentes perfiles de usuario y contraseña para preparar escenarios de práctica con distintos niveles de dificultad.

🛡️

Protección configurable

Defina la cantidad de intentos fallidos permitidos y el tiempo de bloqueo para estudiar mecanismos de protección contra fuerza bruta.

📋

Actividad en tiempo real

Visualice intentos de inicio de sesión, accesos correctos y fallidos mientras realiza las prácticas de autenticación.

Lockout Protection

Estudie el bloqueo de cuentas

Configure cómo debe reaccionar cada servicio ante intentos repetidos de autenticación incorrecta y observe el comportamiento durante las pruebas.

3×

Intentos configurables

Seleccione desde la interfaz cuántos fallos deben producirse antes de bloquear una cuenta.

⏱

Tiempo de bloqueo

Determine cuántos segundos debe permanecer bloqueada una cuenta después de alcanzar el límite.

🔒

Bloqueo efectivo

Mientras la cuenta permanece bloqueada, incluso una contraseña correcta puede ser rechazada hasta finalizar el período.

↻

Reinicio del servicio

Reinicie un servicio para comenzar una nueva práctica limpia sin afectar el estado de los demás protocolos.

CLI + GUI

Interfaz gráfica y terminal

Inicie la interfaz gráfica o gestione servicios individuales directamente desde la terminal de Kali Linux.

kali@rsc:~
$ rsc-targetlab start
$ rsc-targetlab status
$ rsc-targetlab start-service --service ssh
$ rsc-targetlab start-service --service postgresql
$ rsc-targetlab stop-service --service ssh
Kali Linux

Instalar RSC TargetLab

RSC TargetLab 0.1.0 está preparado para instalarse mediante paquete Debian en sistemas Kali Linux AMD64.

RSC TargetLab 0.1.0 Ver código en GitHub

Kali Linux • AMD64 • Versión 0.1.0

1. Actualizar los repositorios
$ sudo apt update
2. Instalar el paquete descargado
$ sudo apt install ./rsc-targetlab_0.1.0_amd64.deb
3. Iniciar RSC TargetLab
$ rsc-targetlab start
Después de la instalación también puede iniciar RSC TargetLab desde el menú de aplicaciones de Kali Linux.
